# Live Project

## Streakly – 75 Day Habit Tracker

Live Demo:

https://streakly-habit-tracker.onrender.com/

Streakly is a habit tracking application that allows users to create habits, track daily or weekday completion, monitor current and best streaks, search habits, and archive or restore habits.

## Tech Stack

- Java
- Spring Boot
- H2 Database
- HTML
- CSS
- JavaScript
- Docker
- Render
